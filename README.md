# Campus Voice 📢
### One campus. One voice.

## 📌 About the Project
Campus Voice is a campus announcement platform designed to keep students informed about college activities and important updates. It provides a centralized place to view announcements related to fests, events, examinations, workshops, and other campus activities.

## 🎯 Objectives
- Provide a centralized platform for campus announcements.
- Keep students updated about important college activities.
- Make announcements easy to find and access.
- Improve communication between students and the college community.

## ✨ Features
- **Announcements:** View college news, events, exams, and fest updates.
- **Search:** Find announcements using keywords.
- **Filtering:** Filter announcements by category.
- **Sorting:** Organize announcements based on available sorting options.
- **Most Viewed:** Identify popular announcements based on views.
- **New Announcement:** Create new announcements through the interface.

## 🛠️ Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive features and functionality

## 🚀 How to Run the Project
1. Clone this repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/campus-voice.git
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the announcements, search, filtering, and sorting features.

Alternatively, open the project in Visual Studio Code or Antigravity and run it using the Live Server extension if available.
